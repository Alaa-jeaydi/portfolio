# علاء جعيدي — معرض أعمال تصميم المواقع

Portfolio of web design demo samples by Alaa Jeaydi.

## Structure

- `index.html` — Services landing page (cinematic style, Arabic RTL)
- `demos/asas-construction.html` — Construction company demo (FIND-style editorial design)
- `demos/construction-classic.html` — Construction landing page demo (cinematic dark style)

> All demo pages are clearly labelled "نموذج تجريبي" (demo sample).

## Publish with GitHub Pages

1. Create a new public repository (e.g. `portfolio`)
2. Upload all files keeping the folder structure
3. Go to Settings → Pages → Deploy from branch → `main` / root
4. Your site will be live at `https://<username>.github.io/portfolio/`
